# Harrington & Co — Private Resort & Hotel

Site vitrine du domaine Harrington & Co (180 hectares) : hôtel 5 étoiles, villas privées, restaurant signature, spa, golf, padel, parc enfants, ferme pédagogique, plage privée, résidences, tenues signature et masterplan interactif.

Site statique : ouvrir `index.html` dans un navigateur, ou l'héberger tel quel (GitHub Pages, Netlify…).

- `index.html` — la page complète (HTML, CSS et JS intégrés)
- `img/` — les photos du domaine

Le formulaire de réservation n'envoie rien pour l'instant : il est à brancher sur un système de réservation.
